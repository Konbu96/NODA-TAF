# 技術構成

> 企画書（[00_project-overview.md](00_project-overview.md)）の条件をもとに、何を使って作るかをまとめた資料です。

---

## 1. 条件

| 条件 | 内容 |
| --- | --- |
| 完全無料 | 無料枠だけで運用できる |
| スマホ向け | スマホのブラウザで快適に使える。ホーム画面に置けるとよい |
| ログインあり | 部員 28 人＋顧問だけが使える。役職ごとに権限を分ける |
| 卒業後も残せる | 長期休みで使わない期間があっても止まらない。管理者を後輩に引き継げる |
| データ量 | 小さい（約 30 人分の記録・メニュー・振り返り） |

## 2. 決定した構成：Next.js ＋ Firebase ＋ Vercel

| 部分 | 使うもの | 役割 |
| --- | --- | --- |
| 画面 | Next.js（App Router）＋ TypeScript | スマホ向けの画面を作る |
| ログイン | Firebase Authentication（Google ログイン） | 部員ごとのログイン |
| データ保存 | Cloud Firestore | 部員・メニュー・記録・振り返りなどを保存 |
| 権限 | Firestore セキュリティルール | 役職ごとに「見られる・編集できる」を制御 |
| 公開 | Vercel（無料の Hobby プラン） | アプリを Web に公開する。GitHub に push すると自動で更新される |
| ホーム画面に置く | PWA | スマホのホーム画面にアイコンを置き、アプリのように開ける |

### 基本の作り方

- データの読み書きとログインは、基本的にスマホ側（ブラウザ）から Firebase に直接行う
- 「誰が何を見られるか」は Firestore セキュリティルールで守る（画面側のチェックだけに頼らない）
- Vercel では Next.js のサーバー側の機能（API ルートなど）も使えるので、必要になったら使う

## 3. ログイン：Google アカウント

- 部員は自分の Google アカウントでログインする
- **登録された部員だけが使えるようにする**：顧問（または開発者）が部員名簿にメールアドレスを登録し、名簿にない人はログインしても何も見られないようにする
- 役職（顧問・キャプテン・副キャプテン・マネージャー・部員）は部員名簿に持たせ、セキュリティルールで参照する

> 注意：学校が配っている Google アカウント（Google Workspace for Education）は、学校の設定によっては外部のアプリにログインできないことがあります。その場合は個人の Google アカウントを使ってもらいます。

## 4. 選んだ理由

ほかの候補との比較

| 項目 | Firebase | Supabase | Google スプレッドシート＋Apps Script |
| --- | --- | --- | --- |
| 料金 | 無料プランで足りる | 無料プランで足りる | 無料 |
| 使わない期間 | **止まらない** | **1 週間使われないと一時停止** | 止まらない |
| 画面の作りやすさ | 自由に作れる | 自由に作れる | スマホ向けの画面は作りにくく、遅め |
| 引き継ぎ | 管理者を追加するだけ | 管理者を追加するだけ | 共有するだけ |

- **長期休みでも止まらない**：夏休みや冬休み明けに使えなくなる心配がない
- **無料枠に十分な余裕がある**：30 人規模なら、1 日の読み書きの上限に届くことはまずない
- **公開が簡単**：Vercel は Next.js を作っている会社のサービスで、GitHub と連携するだけで公開・更新できる

## 5. 無料プランの制限への対応

| 制限 | 影響する機能 | 対応 |
| --- | --- | --- |
| Firebase の無料プランではファイル（PDF・画像）を保存できない | 大会の出場要項 | PDF はアプリに保存せず、大会の公式ページへのリンクを登録する |
| 毎月決まった日に自動で処理を動かす仕組みは使わない | 毎月 25 日の振り返りフォーム | アプリを開いたときに日付を見て「25 日以降なら今月のフォームを表示」とする |
| Vercel の Hobby プランは個人・非営利向け | アプリ全体 | 部活の非営利利用なので問題ない |

> 無料プランの内容は変わることがあるため、開発を始める前に最新の条件を確認します。

## 6. 引き継ぎで考えること（あとで検討）

いまは開発者個人のアカウントで作り、引き継ぎはあとで考えます。そのときに移す必要があるもの：

- GitHub のリポジトリ（いまは開発者個人のアカウント）
- Vercel のプロジェクト
- Firebase のプロジェクト
