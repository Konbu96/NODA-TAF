# Step 2 設計：記録を残せるようにする

> 企画書（[00_project-overview.md](00_project-overview.md)）の Step 2 の設計資料です。
> Step 1 の設計は [02_step1-design.md](02_step1-design.md) を参照。

---

## 1. Step 2 の範囲

| 機能 | 内容 |
| --- | --- |
| 大会記録の入力（C） | 本人が大会の記録を入力する。担当者もあとから直せる |
| 記録のグラフ（C） | 種目ごとに、記録の推移を折れ線グラフで表示する |
| PB の自動更新（C） | 入力した記録が PB より良ければ、マイページの PB を自動で書き換える |
| 他の部員の記録を見る | 「部員」タブから、学年ごとの一覧を開き、他の部員のページを見る |

## 3. 大会記録として残すもの

| 項目 | 例 | 説明 |
| --- | --- | --- |
| 日付 | 2026-10-18 | 大会の日 |
| 大会名 | 〇〇記録会 ／ タイムトライアル | 自由入力。大会以外（記録会・タイムトライアル・合同練習など）の名前も書ける。Step 3 からは登録済みの大会から選ぶこともできる |
| 結果ページのリンク | https://... | 公式の結果ページの URL（なくてもよい） |
| 種目 | 100m | 専門種目と同じ一覧から選ぶ |
| 記録 | 00:11.52 ／ 05.21m ／ 2500点 | PB と同じ書き方 |
| 風速 | +1.2 | 短距離・跳躍などの風が関係する種目だけ |

- 記録を入れられるのは、**アプリを使い始めてからの大会だけ**。それより前の記録は、PB だけマイページに手入力する
- 大会名・日付を一度入れたら、種目と記録を続けて追加できる（複数種目に出た日も 1 回の入力で済む）
- 予選・決勝などで同じ種目に何度か出たときは、**一番良い記録だけ** を入力する

### PB が更新されたとき

- 入力した本人の画面に「PB 更新！ -0.15 秒」のようなお祝いの表示を出す
- メニュー画面に「最近の PB」として、誰がどの種目で PB を出したかを表示する（例：`山田さん 100m 00:11.52 PB 更新！`）
  - 置く場所：今月の目標のすぐ下（メニューの上）
  - 表示する期間：大会の日から 3 日間。過ぎたら自動で消える

```
┌──────────────────────────┐
│ 今月の目標：100m 12秒台     │
├──────────────────────────┤
│ 🎉 最近の PB                │
│  山田さん 100m 00:11.52     │
│  鈴木さん 200m 00:25.10     │
├──────────────────────────┤
│  ◀  10月20日（火） ▶        │
│  （ここから練習メニュー）    │
```

### 記録の修正・削除

- 本人と担当者（顧問・キャプテン・マネージャー）が、記録を修正・削除できる。削除するときは「本当に削除しますか？」と確認を出す
- 修正・削除で PB が変わるときは、残っている記録と手入力の PB の中から、一番良いものに自動で戻す

### 追い風参考記録

- 追い風 2.0m を超えた記録も **PB として扱う**
- ただし、PB・記録一覧・グラフのどこでも「参」の印をつけて、追い風参考だと分かるようにする

表示の例：`100m 00:11.48 参（+2.6）`

## 4. グラフ

- 種目ごとに 1 つの折れ線グラフ
- 横：日付、縦：記録（タイムの種目は、良い記録ほど上になるように表示）
- PB の点を目立たせる。追い風参考の点には「参」の印
- **グラフは自分のマイページでだけ見られる**（他の部員のページには出さない）

## 5. 他の部員のページで見られるもの

| 見られる | 見られない |
| --- | --- |
| 名前・専門種目・ゼッケン番号・PB・大会記録の一覧 | 記録のグラフ・学年・役職 |


## 6. データの形（Firestore）

### records（大会記録）

1 つの種目の記録につき 1 件。

| 項目 | 型 | 例 | 説明 |
| --- | --- | --- | --- |
| memberId | 文字列 | taro@gmail.com | 誰の記録か（members の ID） |
| date | 文字列 | 2026-10-18 | 大会の日 |
| meetName | 文字列 | 〇〇記録会 | 大会名（自由入力） |
| resultUrl | 文字列 | https://... | 結果ページのリンク（なくてもよい） |
| event | 文字列 | 100m | 種目 |
| mark | 文字列 | 00:11.52 | 記録（表示用） |
| value | 数値 | 11.52 | 記録を秒・m・点に直したもの（並べ替え・グラフ用） |
| wind | 数値 | 1.2 | 風速（風が関係ない種目は空） |
| isWindAssisted | 真偽値 | false | 追い風参考（+2.0m を超える）か。風速から自動で決まる |
| updatedBy | 文字列 | taro@gmail.com | 最後に編集した人 |
| updatedAt | 日時 | | 最終更新日時 |

### members の personalBests に足すもの

| 項目 | 型 | 説明 |
| --- | --- | --- |
| value | 数値 | 記録を秒・m・点に直したもの |
| isWindAssisted | 真偽値 | 追い風参考か（「参」の印に使う） |
| recordId | 文字列 | もとになった大会記録の ID（手入力の PB は空） |
| manualMark | 文字列 | 手入力の PB（使い始める前の記録）。自動で戻すときの比較に使う |

### 権限

| データ | 読む | 作る・編集・削除 |
| --- | --- | --- |
| records（自分の分） | 名簿に登録された人 | 本人 |
| records（他の人の分） | 名簿に登録された人 | 顧問・キャプテン・マネージャー・開発者 |

> 「最近の PB」は、records の中から PB を更新した記録（直近 3 日分）を探して表示します。別のデータは作りません。

## 7. 決定ログ

| 日付 | 決めたこと | 理由 |
| --- | --- | --- |
| 2026-10-23 | 大会の記録は本人が入力し、担当者もあとから直せる | 担当者の負担を減らすため |
| 2026-10-23 | 大会記録には風速を残す | 短距離・跳躍では風速で記録の価値が変わるため |
| 2026-10-23 | グラフは種目ごとの折れ線グラフにする | 記録の伸びをひと目で見られるようにするため |
| 2026-10-23 | 「部員」タブは学年ごとの部員一覧から始める | 部員を名簿のように探せるようにするため |
| 2026-10-23 | 追い風参考記録も PB にするが、「参」の印をつける | 記録としては残したいが、公式記録と区別できるようにするため |
| 2026-10-23 | 大会名は自由入力で、大会以外の名前や結果ページのリンクも残せる | 記録会やタイムトライアルの記録も残したいため |
| 2026-10-23 | 他の部員のページでは、専門種目・ゼッケン・PB・大会記録の一覧だけを見せる | 必要な情報だけにして、見やすくするため |
| 2026-10-23 | 記録はアプリを使い始めてからの分だけ入力する（それ以前は PB のみ手入力） | 過去の記録を入れる手間を省くため |
| 2026-10-23 | PB 更新時は本人にお祝いを表示し、メニュー画面に「最近の PB」を出す | 部内を盛り上げるため |
| 2026-10-23 | 1 つの大会で複数の種目を続けて入力できる | 大会名・日付を何度も入れずに済むようにするため |
| 2026-10-23 | 同じ大会・同じ種目は一番良い記録だけを入力する | グラフをすっきりさせるため |
| 2026-10-23 | 「最近の PB」は今月の目標のすぐ下に、大会の日から 3 日間表示する | 開いてすぐ目に入り、画面が古い情報で埋まらないようにするため |
| 2026-10-23 | 記録は本人・担当者が修正・削除でき、PB は残った記録から自動で戻す | 入力ミスを直せて、間違った PB が残らないようにするため |
