# Step 4 設計：月末の振り返り

> 企画書（[00_project-overview.md](00_project-overview.md)）の Step 4 の設計資料です。
> 画面の基本（丸ボタン・ヘッダー・☰）は [02_step1-design.md](02_step1-design.md) を参照。

---

## 1. Step 4 の範囲

| 機能 | 内容 |
| --- | --- |
| 月末の振り返り（F） | 毎月 25 日に新しいフォームが出て、部員がアプリ内で提出する |
| 今月の目標の表示 | 振り返りで書いた「来月の目標」を、メニュー画面の一番上に表示する |
| 提出状況 | 何人中何人が提出したか、未提出の人の名前を全員が見られる |
| みんなの目標 | 部員画面で、各部員の名前の下に「来月の目標」を 1 行で表示する |

## 2. 振り返りの質問

| # | 質問 | 回答の形式 |
| --- | --- | --- |
| 1 | あなたの先月の個人目標は何でしたか？ | 自由記述（先月の質問 4 を自動で入れておく） |
| 2 | 目標をどのくらい達成できたか、自分が思うものを選んでください | 5 段階（1 = 達成できなかった 〜 5 = 完璧に達成できた） |
| 3 | この 1 か月で、目標のどの部分が達成できたか・できなかったか、新たに生まれた課題について具体的に書いてください | 自由記述 |
| 4 | 上記の内容や前期（先月）の目標を参考に、来月の個人目標を入力してください | 自由記述 |

- 「前期の目標」は先月の目標のこと。前の月の振り返りから自動で表示するので、別に入力する必要はない

## 3. 流れ

1. 毎月 25 日に、その月のフォームが出る（締め切りはなく、次の 25 日まで提出できる）
2. 未提出の間は、丸ボタンの行き先「マイページ」の角に印がつく。丸ボタンが閉じているときは、丸ボタンの角に点がつく
3. マイページのフォームから提出する。**提出したら直せない**
4. 提出すると、質問 4 の「来月の目標」がメニュー画面の一番上に表示される（次の目標を出すまで）

## 4. 公開範囲

| 内容 | 見られる人 |
| --- | --- |
| 質問 1〜3 | アプリ内では本人だけ。他の人の振り返りを見る機能はアプリに作らず、見たい人はスプレッドシートを開く |
| 質問 4（来月の目標） | 全員（部員画面に表示。メニュー画面などには出さない） |
| 提出状況（例：28 人中 20 人提出済み）と未提出の人の名前 | 全員（部員画面の一番上に表示） |

### 部員画面での表示

```
┌──────────────────────────┐
│野田学園      部員           │
│陸上競技部                   │
├──────────────────────────┤
│ 10月の振り返り  20/28人提出  │
│ ■■■■■■■□□□             │
│ 未提出：〇〇、〇〇、…        │
├──────────────────────────┤
│ 🔍 名前で探す               │
├──────────────────────────┤
│ ▼ 高2（6人）                │
│  〇〇 〇〇   123・100m/200m │
│  目標：〇〇〇〇〇〇          │
│  〇〇 〇〇   152・400m      │
│  未提出                     │
│ ▶ 高1（11人）               │
└──────────────────────────┘
```

- 未提出の人は、目標の代わりに「未提出」と表示する

- 自分の過去の振り返りは、マイページで月ごとに見返せる

## 4-2. スプレッドシートへの自動書き込み

- フォームが提出された瞬間に、Google スプレッドシートへ自動で 1 行書き込む（Vercel のサーバー側の処理から Google Sheets API を使う。無料）
- スプレッドシートは部専用アカウントで作る
- 書き込む内容：学年・名前・達成度・先月の目標・振り返り（質問 3）・来月の目標・提出日

見やすくする工夫

| 工夫 | 内容 |
| --- | --- |
| 学年ごとに並べて区切る | 提出された順ではなく、高 3 → 中 1 の順に並べ、学年の間に区切りを入れる |
| 長い文章を折り返す | 文章の列は幅を決めて、セルの中で改行して読めるようにする |
| 達成度を色分けする | 1〜2 はオレンジ、3 は黄、4〜5 は緑など |
| 見出しを固定する | 下にスクロールしても、一番上の見出しの行が残る |

シートの分け方：**年度ごとに 1 つのタブ。中は月ごとに折りたたむ**

```
下のタブ： [2026年度] [2025年度]

■ 2026年度 タブ（新しい月が一番上）
[−] ══ 11月（20/28人提出）═══════════
     高2 │〇〇│🟩 4│12秒台│スタートは…│11秒台
     高2 │〇〇│🟧 2│5m50 │助走が…    │助走安定
     ───────────────────────
     高1 │〇〇│🟨 3│…    │…          │…
[+] ══ 10月（25/28人提出）═══════════
[+] ══ 9月（22/28人提出）════════════
```

- 月ごとに行をグループ化し、＋／− で開閉できるようにする（スプレッドシートの「行のグループ化」機能）
- 新しい月は一番上に追加し、今月だけ開いた状態にする。前の月は自動でたたむ
- 月の見出しの行に、その月の提出人数を表示する
- 4 月になったら、新しい年度のタブを自動で作る
- 「まとめ」シートは作らない

見られる人：**部員全員（見るだけ。書き換えはできない）**

- 部員が承認されたときに、その人の Google アカウントへ自動で「閲覧のみ」で共有する。卒業・退部で削除したときは共有も外す
- 「リンクを知っている人は誰でも見られる」設定にはしない（部外の人に見られないようにするため）
- 部員画面の提出状況の欄に「スプレッドシートを開く」リンクを置く

## 5. 先月の目標がない人

| 人 | フォームの表示 |
| --- | --- |
| 途中で入部した人（先月はまだ部員でなかった） | 質問 1・2 を飛ばし、来月の目標（と質問 3）だけ書く |
| 先月も部員だったのに、先月の振り返りを出していない人 | フォームの一番上に、赤い枠で「10月の振り返りが未提出です」と危機感のある表示を出す。質問 1 は自分で書いてもらう |

## 6. 決定ログ

| 日付 | 決めたこと | 理由 |
| --- | --- | --- |
| 2026-10-23 | 振り返りフォームはマイページに置き、未提出の間は丸ボタンの「マイページ」に印をつける | メニュー画面の要素を増やさないため |
| 2026-10-23 | 振り返りは提出したら直せない | |
| 2026-10-23 | 「前期の目標」は先月の目標のことで、前の月の振り返りから自動で表示する | 別に入力する手間をなくすため |
| 2026-10-23 | 質問 1〜3 はアプリ内では本人だけが見られる（顧問・キャプテンにも見せない） | |
| 2026-10-23 | 途中入部の人は質問 1・2 を飛ばす。先月も部員なのに未提出だった人には、フォームに危機感のある警告を出す | 提出を習慣にしてもらうため |
| 2026-10-23 | 自分の過去の振り返りはマイページで月ごとに見返せる | 自分の成長や調子の波を振り返れるようにするため |
| 2026-10-23 | みんなの目標と提出状況は、部員画面に直接表示する | 別の画面に移らなくても見られるようにするため |
| 2026-10-23 | 名前と一緒にゼッケン番号・専門種目を出すのは部員画面だけにする | ほかの画面では不要な情報を減らすため |
| 2026-10-23 | 振り返りは提出された瞬間にスプレッドシートへ自動で書き込む | 振り返りをスプレッドシートにまとめたいため |
| 2026-10-23 | スプレッドシートは学年順・文章の折り返し・達成度の色分けで見やすくする | 情報の羅列にならないようにするため |
| 2026-10-23 | アプリには他の人の振り返りを見る機能を作らない。スプレッドシートは部員全員が閲覧できる | 見たい人はスプレッドシートを開けばよく、アプリがかさばらないため |
| 2026-10-23 | スプレッドシートは部員の Google アカウントに閲覧のみで自動共有する（リンク公開はしない） | 部外の人に見られないようにするため |
| 2026-10-23 | 部員画面の「来月の目標」の表示は残す | 目標は部内で共有したいため（振り返りの中身とは分けて考える） |
| 2026-10-23 | スプレッドシートは年度ごとに 1 つのタブにし、中を月ごとに折りたたむ。まとめシートは作らない | タブを増やさず、今月の分を見やすくするため |
