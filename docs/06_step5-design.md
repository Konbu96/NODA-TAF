Step 5 に **入れないもの**

## 2. スタブロの練習記録

| 項目 | 内容 |
| --- | --- |
| 記録するもの | 30m・60m・80m のタイム（それぞれ別々に走って測る） |
| 基本の本数 | 30m × 2 本、60m × 2 本、80m × 1 本 |
| 測り方 | 手動のストップウォッチ（他の部員やマネージャーが測る） |
| 記録の本数 | 1 本ずつ全部。距離ごとのベストは自動で出す |
| 見られる人 | 全員 |

入力画面のイメージ

```
10月24日 スタブロ
 30m  [ 4.30 ] [ 4.25 ]      ベスト 4.25
 60m  [ 7.45 ] [ 7.40 ]      ベスト 7.40
 80m  [ 9.80 ]               ベスト 9.80
       ＋ 本数を増やす
```

- 最初から基本の 5 本分の入力欄を用意しておく
- その日によって本数を増やしたり減らしたりできる

### 誰が入力するか

- 基本は **測った人（ストップウォッチを持っている人）** が、その場で入力する
- 1 回で何人分も測るので、**距離ごと（30m・60m・80m）のタブ** に分け、名前を縦に並べてそこに書き込む
- 並ぶ名前は、その日に **競技場に「行く」と答えた人だけ**
- タイムは数字だけ打つと点が入る（425 → 4.25）。走らなかった人の欄は空のままでよい
- 「−／＋」で、選んでいる距離の欄を全員まとめて 1 本ずつ減らす・増やす（最低 1 本）。あまり使わないので、名前の一覧の下の真ん中に、薄い灰色の小さな「− 2本 ＋」だけを置く
- 部員なら誰でも、他の部員の記録を入力できる（測る人が決まっていないため）。間違いは本人・顧問・キャプテン・マネージャーが直せる

```
10月27日 スタブロ（入力：測った人）
 [30m]  60m   80m
 競技場に行く人（8人）  1本目  2本目
 〇〇                  [4.30] [4.25]
 〇〇                  [4.41] [4.38]
 〇〇                  [    ] [    ]
 …
               − 2本 ＋
```

### グラフ

- マイページに、距離ごと（30m・60m・80m）の **日ごとのベスト** を折れ線グラフで表示する（大会記録のグラフと同じ形）
- グラフは自分のマイページだけ。他の部員のページには出さない
- マイページの「スタブロのグラフを見る」から開く。上に 30m／60m／80m の切り替え、その下にベスト（タイムと日付）、グラフ（速いほど上。ベストの日はオレンジの大きな点）
- グラフの下に「日ごとの記録」を新しい順に並べ、その日の全部の本数のタイムを出す。ベストの日には「ベスト」の印。最初は 5 日分だけ出し、「もっと見る」で全部出す
- 他の部員のページには、**距離ごとのスタブロのベスト**（30m・60m・80m）を表示する。競い合うきっかけにするため

### 入力画面の開き方

- 練習メニューに「スタブロ」が入っている日だけ、メニュー画面の練習メニューの中に「スタブロの記録をつける」ボタンを出す
- ボタンを押すと、その日の日付が入った状態で入力画面が開く

## 3. 今日の気分

> 画面イメージ：https://claude.ai/artifact/8AYihtbYiZYe2UV1gXxYy3 の「今日の気分」

| 顔 | 見た目 | 色（パステル） |
| --- | --- | --- |
| 絶好調 | にっこり目と大きく開いた口 | 黄 |
| いい感じ | 笑顔 | 緑 |
| ふつう | まっすぐな口 | グレー |
| ねむい | 閉じた目と「z」 | 水色 |
| へとへと | ×の目と汗 | オレンジ |
| 足が痛い | 困った眉とほっぺの絆創膏 | ピンク |
| 体調悪め | マスク | 黄緑 |

- 顔はアプリで描いたイラスト（絵文字ではない）。パステルカラーで目に優しくする
- **その日初めてアプリを開いたときに 1 回だけ**、画面全体に「今日の気分は？」を出す
- 閉じるボタン・「あとで」は置かない。顔を 1 つ選ぶとメニュー画面に進む
- 顔は 4 つ・3 つの 2 段に、大きめに並べる
- 画面の文字は、日付と「今日の気分は？」だけ
- 顔を押すと、選んだ顔が少し大きくなり、ほかの顔は薄くなる。0.7 秒ほどでメニュー画面に進む
- 一度選んだ気分は、その日のうちには変えられない
- 「今日」は夜中の 0 時に切り替わり、気分もリセットされる
- 選んだ気分は、部員画面の名前の右に小さく表示する
- 顔が出ていない人は「今日まだアプリを開いていない人」と分かる
- 記録やグラフは残さない。その日だけの表示で、次の日にはリセットされる

## 4. スマホへの通知

| 通知 | 送る相手 | 送るとき |
| --- | --- | --- |
| 練習メニューが登録・変更された | 全員 | 登録・変更されたとき |
| 入部申請が来た | 顧問・キャプテン | 申請されたとき |
| 月末の振り返りフォームが出た | 全員 | 毎月 25 日 |
| 大会の記録を入力しよう | その大会にエントリーした人 | 大会の翌日 |

- iPhone は、アプリをホーム画面に追加した人だけが通知を受け取れる（iPhone の仕組みによる制限）。最初に使うときに、ホーム画面への追加のしかたを案内する
